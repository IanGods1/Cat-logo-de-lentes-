🛒 Mi pedido

Se abre el menú “Compartir” del teléfono: elija WhatsApp y luego al proveedor. Cada foto lleva escrito abajo el número, la cantidad y la nota.

❓ Cómo usar el catálogo

1. Elegir los lentes

  1. Busque el lente que le gusta. Cada foto tiene su número arriba a la izquierda.
  2. Toque + debajo de la foto para poner cuántos quiere (o escriba el número). Con − resta.
  3. Toque la 🔍 de la foto para verla en grande. Ahí también puede poner la cantidad y una nota (ej. “solo los negros”).
  4. En la foto grande puede acercar con 🔍+ y arrastrar con un dedo para moverla. Con − vuelve al tamaño normal. Deslizar a los lados (sin zoom) pasa a la otra foto. Tocar la foto en la lista ya no hace nada, así no se abre sin querer.
  5. ¿Solo quiere algunos colores? En la foto grande toque ✏️ Marcar. Con ✅ Palomita toque cada color que quiere; con ✏️ Lápiz puede encerrar o rayar con el dedo. ↩ Deshacer quita la última marca. Toque Listo al terminar. Las marcas se mandan dibujadas en la foto al proveedor.
  6. Con 🛒 Elegidas ve solo los que ya escogió.

2. Enviar el pedido al proveedor

  1. Toque la barra verde 🛒 Ver y enviar de abajo.
  2. Revise cantidades y notas. Escriba el WhatsApp del proveedor (solo la primera vez; queda guardado).
  3. 📸 Enviar con fotos: se abre “Compartir”; elija WhatsApp y al proveedor. Le llegan las fotos con la cantidad escrita abajo de cada una, más la lista completa.
  4. Si eligió más de 30 lentes, se mandan en grupos de 30: después del primero toque el botón otra vez para el siguiente grupo.
  5. 💬 Solo la lista: abre el chat del proveedor con la lista escrita (sin fotos).

3. Cuando el proveedor mande un catálogo nuevo

  1. Copie el link del álbum de Google Fotos que le mandó.
  2. Toque 🔄 arriba, pegue el link y toque Actualizar catálogo.
  3. En 2 a 5 minutos la página cambia sola: quedan solo las fotos nuevas y se borran las anteriores.

4. Si el proveedor manda un PDF o fotos sueltas

  1. Guarde el PDF o las fotos en el teléfono (en WhatsApp: abrir el archivo → Compartir → Guardar en Archivos).
  2. Toque 🔄 → Opción 2 → 📄 Elegir archivos y escoja los PDF o fotos (puede ser varios).
  3. Elija Reemplazar todo o Agregar al final y toque Subir y actualizar. Deje la pantalla abierta hasta que diga ✅ Listo.

Lo que elige se guarda en este teléfono. Si se actualiza el catálogo, el pedido se vacía porque las fotos cambian.

🔑 Clave de GitHub (solo la primera vez)

Para que este botón funcione, el teléfono necesita una clave de GitHub. Se guarda solo en este teléfono.

  1. En github.com entre a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elija “Only select repositories” → Cat-logo-de-lentes-.
  3. En Permissions → Actions → “Read and write” y también Contents → “Read and write” (este último es para subir PDF o fotos).
  4. Genere la clave, cópiela y péguela aquí.

Sin clave también se puede usar el link: abra GitHub → Actualizar catálogo, toque Run workflow, pegue el link y confirme.
